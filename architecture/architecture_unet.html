Attention U-Net

3 classes (background, liver, tumor)  •  input 256×256×1  •  base_filters=32  •  depth=4  •  0 attention gates
Encoder–decoder with an attention gate on every skip connection. The encoder answers what is in the image and discards position; the decoder walks the resolution back up to answer where. Skip connections carry back the spatial detail the encoder threw away — and each gate filters its skip first, using the coarser decoder tensor as the query, so only the relevant regions pass through.

Each gate computes alpha = sigmoid(psi(relu(Wg(g) + Wx(x)))) — a single-channel map in 0..1 that scales the skip. One channel, so it broadcasts: the gate chooses where to look, not which feature to keep.
Conv layers carry no bias when batch_norm=True, since BatchNorm subtracts the mean and would cancel it.
